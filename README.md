# Plugins

Figma dev-плагины для продуктового дизайна.

## Token Inspector — `token-inspector`

Смотреть, какие компоненты используют переменную Figma, и наоборот — прямо из Figma,
без выгрузки в таблицы. Работает с любым типом переменных: цвет, spacing, radius, sizing,
типографика. Есть режим поиска неиспользуемых переменных.

Установка и подробности — [token-inspector/README.md](token-inspector/README.md).

## English

Figma dev plugins for product design.

**Token Inspector** — find which components use a given Figma variable, and vice versa,
right inside Figma. Works with any variable type: color, spacing, radius, sizing, typography.
Includes a dead-variable finder. See [token-inspector/README.md](token-inspector/README.md).
